# ComfyBar 0.1.0 - first public release

See your local ComfyUI from the macOS menu bar, and start, stop and interrupt it.

- **Menu-bar mark** (an open C with a B inside): the C shows the state - grey not running,
  green idle, blue running (filling with progress), orange queued, red error - and the B
  follows your light or dark menu bar. Optional text: progress %, queue length, memory in use
  or elapsed time.
- **Panel**: server status, version, uptime and memory; the current job with who queued it,
  node, step x/y, elapsed and the sampler's own estimate; queue and recent jobs; this Mac's
  memory, swap and pressure signals. Every figure names its source.
- **Controls**: Start, Stop, Restart, Interrupt, Cancel a queued job, Clear the queue, Free
  memory, open ComfyUI / the output folder / the log. Anything that ends work asks first and
  names the job.
- **Notifications**: job finished, job failed, server went down (each switchable).
- **Safe by default**: Start never binds anything but 127.0.0.1 - `--listen`, `--port`, TLS and
  CORS options (including argparse abbreviations like `--liste`) are refused, and a server
  ComfyBar started that turns up on a non-loopback address is stopped at once.

Requires macOS 14 or later and a ComfyUI install with a `venv` (default `~/ComfyUI`).
